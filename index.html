RFP Google Sheets Extension
RFP Sheets is a Chrome extension developed in TypeScript that integrates Adminwise's Server API to streamline Help Ticket submission directly from Google Sheets to Adminwise.
The extension parses spreadsheet data and uses it to automatically populate ticket fields from the spreadsheet to minimize the amount of manual data entry required. I also created user and developer documentation covering the extension's setup, usage, and common troubleshooting steps.
Technologies: TypeScript, Chrome Extensions, Google Sheets, Server API Integration
BCIT Online S.M.A.R.T. Microgrid Admin Panel
BCIT Online S.M.A.R.T. (Smart Microgrid Applied Research Team) Microgrid Admin Panel is an interactive user interface for administrators to manage user data and database records. My contributions included designing and working with the SQL database, implementing CRUD (Create, Read, Update, Delete) functionality, and developing backend server APIs which included validation with sanitization to prevent invalid input and SQL injection.
I also worked with an Ubuntu virtual machine and PuTTY for remote access during development and deployment. Throughout the project, I collaborated with my team members to integrate our work and troubleshoot issues as they arose in an Agile environment.
Technologies: Ubuntu, PuTTY, Javascript, SQL, API Endpoint Development
C Chatroom Client
C Chatroom Client is a C-based chat application that uses sockets for network communication and ncurses for its terminal-based interface.
I implemented server connections, messaging, nickname selection, and input editing, while handling network byte order for communication across machines.
Technologies: C · Sockets · Network Programming · ncurses · Git · Client-Server Architecture
TaleTyrant - AI Story Generator
TaleTyrant is an interactive web application that uses a GPT-2 language model hosted through Hugging Face to generate stories based on user-provided text. Users enter a prompt through the website, which is processed and sent to the language model to generate a continuation that is returned and displayed on the page.
I worked on connecting the user interface to the AI model, handling user input and generated responses, and presenting the resulting story in a simple web interface.
Technologies: GPT-2 · Hugging Face API Integration · JavaScript · HTML · CSS · API Integration
