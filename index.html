My name is Kiefer Thom. I am a Computer Systems Technology graduate from BCIT with a background in software development and a strong interest in understanding how technology works.

RFP Google Sheets Extension
RFP Sheets is a Chrome extension developed in TypeScript that integrates with Adminwise's Server API to streamline Help ticket creation directly from Google Sheets.
The extension parses spreadsheet data and uses it to automatically populate ticket fields, reducing the amount of manual data entry required. I also created user and developer documentation covering the extension's setup, usage, and common troubleshooting steps.
Technologies: TypeScript, Chrome Extensions, Google Sheets, Server API Integration
BCIT Online S.M.A.R.T. Microgrid Admin Panel
I worked as part of a team to develop the S.M.A.R.T. administrative panel for managing user accounts and data. My contributions included designing and working with the SQL database, implementing CRUD functionality, and developing API validation with sanitization to prevent invalid input and SQL injection.
I also worked with an Ubuntu virtual machine and PuTTY for remote access during development and deployment. Throughout the project, I collaborated with my teammates to integrate our work and troubleshoot issues as they arose.
Technologies: Ubuntu, PuTTY, Javascript, SQL, API Endpoint Development
Chatroom Client
I developed the client-side of a C-based chatroom application, building features for connecting to the server, sending and receiving messages, selecting a nickname, and editing user input. I used `ncurses` to create the application's text-based interface.
I implemented communication between machines using C sockets and worked with network byte order to ensure data was correctly interpreted between the client and server. I also collaborated with the server-side team using Git branching workflows, integrating features and performing structural testing as the project developed.
Technologies: C · Sockets · Network Programming · ncurses · Git · Client-Server Architecture

AI Story Generator
An interactive web application that uses a GPT-2 language model hosted through Hugging Face to generate stories based on user-provided text. Users enter a prompt through the website, which is processed and sent to the language model to generate a continuation that is returned and displayed on the page.
I worked on connecting the user interface to the AI model, handling user input and generated responses, and presenting the resulting story in a simple web interface.
Technologies: GPT-2 · Hugging Face · JavaScript · HTML · CSS · API Integration
